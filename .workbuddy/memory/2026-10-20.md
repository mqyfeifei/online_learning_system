## 本机踩坑记录
- Git Bash 必须用 `mvn.cmd`，裸 `mvn` 报 classworlds Launcher 错。
- WorkBuddy 终端注入变量 `SERVER__PORT=54697`，被 Spring Boot 松散绑定当成 server.port（优先级高于 application.yml），导致端口跑飞。规避：`env -u SERVER__PORT`。用户自己的 IDEA/CMD 无此变量。
- curl 探测本机服务要加 `--noproxy '*'`（否则走系统代理报 upstream connect failed）。
- MySQL root **不是空密码**，也不是 123456。
- bash heredoc 写含 `${}` 模板字符串的 .vue 会报 `Bad substitution`，改用 Write 工具。
- 前端 tsconfig.node.json 需要 `@types/node`，否则 `vue-tsc -b` 报 TS2688。

### 联调发现并修掉的 5 处问题（提交 c1a8a5a）
1. 学生答题响应出现 `"answer":null` —— 逻辑本不泄露，但 Jackson 默认序列化 null。`QuestionVO` 加 `@JsonInclude(NON_NULL)`。
2. 管理端分类饼图显示「分类 5」—— `StatsService.platform()` 用 categoryId 当 key。改为查 `course_category` 映射成分类名。
3. 教师看板环形图配色每次刷新都变 —— 成绩分桶用 `Map.of`（迭代顺序随机），前端按顺序取默认色盘。改 `LinkedHashMap` 固定 90-100→0-59，前端再按分数段写死配色。
4. 教师看板 y 轴出现 1.5 刻度 —— 柱状图 `yAxis` 加 `minInterval: 1`。
5. 课程封面把标题 `slice(0,6)` 截成「Java 程」—— 去掉截断，`.cover` 加内边距 + 居中，最多两行。

另外：成绩页时间列原来直接输出 ISO（带 T），改走 `fmt()`；README 补「联调验收结果」表；`docs/screenshots/` 归档 7 张验收截图。

### agent-browser 使用坑
- 每个 Bash 调用里 `agent-browser open` 之后浏览器上下文会丢，页面变空白（`document.documentElement` 只有空 html）。**登录取 token → 跳转 → 断言/截图必须写在同一条 Bash 命令链里**。
- 命令输出用管道（`| tail`）容易被 SIGTERM 打断，改成 `> 文件 2>&1` 再 cat。
- ref（@e1 之类）只在同一次 snapshot 内有效，跨调用失效；宁可用 CSS 选择器（`input[placeholder='请输入用户名']`）。
