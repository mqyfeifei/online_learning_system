# 2026-10-29

## 学生端「成绩与测验」页：课程标签改为全页统一筛选
- 文件：`olearning-web/src/views/Grades.vue`（前端单文件改动，后端无改动）。
- 原问题：`filterCourseId` 只影响「测验记录」列表和「作业与测验明细」表格；平均分、成绩记录数、最高分、成绩趋势、等级分布仍取全量 `summary`，切标签后数据不一致。
- 改法：新增 `allItems`（全量成绩明细，含 courseId）→ `filteredItems` / `filteredRecords` 两个筛选派生集；所有卡片与图表改为从 `scopedStats`（由筛选集推导）取数：
  - 平均分 / 最高分 / 成绩记录条数 / 作业与测验拆分 → `filteredItems`
  - 测验次数 / 及格率 → `filteredRecords`（无记录时及格率显示 —）
  - 趋势折线、等级分布 → `filteredItems`
- 标签来源改为 `allItems` ∪ `records` 的课程并集，只有作业没有测验的课程也能筛到；标签数字 = 该课程成绩条数。
- 交互补充：页面顶部新增筛选范围条（`scope-bar`，显示当前课程 + 一键回到全部）；`pickCourse()` 点同一标签再次点击取消；各段落标题都带 `scopeLabel`；空状态按是否筛选显示不同文案。
- 校验：`vue-tsc --noEmit` 通过、`vite build` 通过；用 student1(20210001) 的真实数据核对：全部 10 条平均 28.1/最高 88，按课程分别为 数据库系统综合实验 25.0、计算机网络 65.3、Java 程序设计基础 10.0，切换后数值确有变化。
- 注意：登录接口 DTO 字段是 `account`（不是 `userNo`），前端 stores 里映射过；用 curl 调试时要传 `account`。
